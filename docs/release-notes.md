Menu Paramètres et code de transfert.

## Installer / mettre à jour
Télécharge `HillKicker-v0.7.0.apk` ci-dessous depuis ton téléphone et ouvre-le : il s'installe par-dessus la version précédente, ta progression est conservée.

## Nouveautés
- **Menu Paramètres** (roue dentée de l'accueil) : un curseur pour le volume de la musique, un autre pour les effets sonores.
- **Code de transfert** (Paramètres › Sauvegarde) : ta partie entière dans un code `HK1-…` à copier ou à noter. Sur un autre téléphone, colle-le dans « Récupérer une partie » pour retrouver ton niveau, tes monnaies, tes améliorations et tes véhicules. Aucun compte ni connexion nécessaires.
- Le code refuse les fautes de frappe au lieu de charger une partie abîmée, et demande confirmation avant de remplacer la partie en cours.
- **Effacer la partie** demande maintenant deux appuis.
